## 製品概要

### 背景(製品開発のきっかけ、課題等）

近年の教育現場の情報化により，小中学校へのパソコン普及率は飛躍的に上がりました．
しかし，一般のご家庭で普段からパソコンを触っている割合は低く，基本的な捜査につまずきやすいのが現状です．
そこで今回私たちは，パソコンの操作に慣れることを目標としたwebゲームを作成することにしました．

[参考文献:文部科学省](https://www.e-stat.go.jp/stat-search/files?page=1&layout=datalist&toukei=00400306&tstat=000001045486&cycle=0&tclass1=000001247037&tclass2=000001247038&tclass3val=0)

### 製品説明（具体的な製品の説明）

webアプリケーションゲームであり，パソコンで頻繁に使用するショートカットキーを勉強するのがテーマです．
ゲームの内容は，キーボードとマウスを操作してパズルステージをショートカットキーを使いながらキャラクターを操作して脱出を目指すものとなってます．
