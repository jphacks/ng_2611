## 製品概要

### 背景(製品開発のきっかけ、課題等）

近年のGIGAスクール構想などの教育現場の情報化により，小中学校へのパソコン普及率は飛躍的に上がりました．
しかし，一般のご家庭で普段からパソコンを触っている割合は低く，基本的な操作につまずきやすいのが現状です．
実際、基本的な操作であるショートカットキーは業務や作業でしか使うことしかなく**つまらなくて覚えるのもめんどくさい**
というのが子供の視点です。
そこで私たちは「どうやったらパソコンを触る時間を増やせるのか」「どうすれば楽しくなるか」という点で考えたとき、
ショートカットキーを活用したパズルゲームというものを考案しました。
実際の前例として寿司打というタイピング×ゲームの成功例があるためある程度は効果が期待できるものとなっています。

[参考文献:文部科学省　GIGAスクール構想](https://www.e-stat.go.jp/stat-search/files?page=1&layout=datalist&toukei=00400306&tstat=000001045486&cycle=0&tclass1=000001247037&tclass2=000001247038&tclass3val=0)

[参考文献:一般のご家庭のパソコン普及率](https://lab.edu-net.co.jp/Press_release/press_2026_2)

### 製品説明（具体的な製品の説明）

webアプリケーションゲームであり，パソコンで頻繁に使用するショートカットキーを勉強するのがテーマです．
ゲームの内容は，キーボードとマウスを操作してパズルステージをショートカットキーを使いながらキャラクターを操作して脱出を目指すものとなってます．
また、実際の教育現場に導入をしやすいようにgoogleアカウントでログインしてホスト(先生)がルームを作成して授業で使うことも可能です。
今回scrachといったゲーム作成フレームワークをあえて使わなかったのも、教育現場などで使うとするとセキュリティにも気を付ける必要があるので、一から作成しました。

#### 基本的な操作

プレイヤーの移動：

w a s d　または　←　↑　→　↓　の4方向移動

使用するショートカットキー：
- ctrl c
- ctrl v
- ctrl a
- ctrl z
- ctrl y
- ctrl s

- レーザー

- スキルポーション
