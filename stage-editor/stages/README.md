# ステージデータの置き場（メモ）

完成したステージJSONの正式な置き場は **ルートの `src/data/stages/`** です。このフォルダには完成JSONを置きません。

## 作成手順

1. エディタ（`editor/`）でステージを作る。
2. `npm run validate:stages` を通す。
3. `{id}.json` を `src/data/stages/` に置く。
4. ゲームを再読み込みし、`number` 順に表示されることを確認する。
5. 解法を実際に手でたどり、詰み状態にならないことを確認する。

## ルール

- `id` はファイル名（拡張子なし）と一致させる。
- `number` は全ステージで一意。
- 同じ座標に複数の要素を置かない。
- 外周は固定壁。配置可能範囲は `x: 1〜22`、`y: 1〜14`。
- 仕様は `shared/STAGE_FORMAT.md`、ギミックは `docs/GIMMICKS.md` を正とする。
