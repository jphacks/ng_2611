# ステージデータ

編集側で作成したJSONを置く。AIがステージを作る時は必ず `../../shared/STAGE_FORMAT.md` と `../../docs/GIMMICKS.md` を読んでから作成する。

## 作成手順

1. `move-intro.json` のように英小文字ハイフン区切りでファイルを作る。
2. `id` はファイル名（拡張子なし）と一致させる。
3. 壁で外周を囲み、`start` 1個と `goal` 1個以上を配置する。
4. ギミックを使う時は、対応する `group` をすべて同じ文字列にする。
5. 解法を実際に手でたどり、詰み状態にならないことを確認する。

例：`move-intro`、`copy-gate-intro`、`switch-bridge`。同じ座標を複数回書かない。
