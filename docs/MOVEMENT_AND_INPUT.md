# 移動キー・入力仕様

## 基本方針

ゲーム画面がフォーカスされている間だけキー入力を受け取る。ブラウザ標準のスクロールや保存ダイアログを起動させないため、ゲームが使用するキーは `preventDefault()` する。ただし入力欄にフォーカスがある時は何もしない。

## 移動キー

| 操作 | キー | `KeyboardEvent.code` | 移動量 |
|---|---|---|---|
| 上 | ↑ / W | `ArrowUp` / `KeyW` | `(0, -1)` |
| 下 | ↓ / S | `ArrowDown` / `KeyS` | `(0, +1)` |
| 左 | ← / A | `ArrowLeft` / `KeyA` | `(-1, 0)` |
| 右 | → / D | `ArrowRight` / `KeyD` | `(+1, 0)` |

- 1回のキー押下で1マス進むターン制にする。キーを押し続けた連続移動はMVPでは実装しない。
- 壁・範囲外・通行不能なギミックには移動しない。失敗時もプレイヤー座標は変えない。
- 移動できた時だけ、移動後のマスの効果を解決し、クリア判定を行う。
- `event.key` ではなくキーボード配列に左右されにくい `event.code` を使う。

## ショートカットキー

| アクション | キー | 発火条件 | 想定用途 |
|---|---|---|---|
| コピー | Ctrl/Cmd + C | コピー可能マス上 | コピー対象を保持 |
| 貼り付け | Ctrl/Cmd + V | 貼り付け可能マス上 | 保持対象を配置／扉を開く |
| 切り取り | Ctrl/Cmd + X | 切り取り可能マス上 | 対象を回収 |
| 元に戻す | Ctrl/Cmd + Z | 行動履歴あり | 直前の行動を巻き戻す |
| リトライ | R / Enter | いつでも | 現在ステージを初期状態へ戻す |

`Ctrl` と `Meta`（MacのCommand）を同じ「修飾キー」として扱う。ブラウザのコピー・貼り付けを防止するのは、ゲームCanvasがアクティブで該当ギミックが存在する時だけに限定する。

## 実装の責任分担

- `InputHandler`：キーイベントをゲーム用のアクションへ変換する。状態変更はしない。
- `GameState`：移動・ショートカットを受け、合法か確認して状態を更新する。
- `Renderer`：状態を描画するだけで、入力やルールを持たない。
- `GameScene`：上の3者をつなぎ、更新・描画・ステージ再開を管理する。
