# ギミック仕様（既存 `MainGameScene` 準拠）

ゲームプレイに残すギミックの動作仕様。

| 要素 | データ | 挙動 |
|---|---|---|
| 固定壁 | `obstacles` | 常に通行不可。矩形で定義 |
| 木箱 | `blocks` | 通常は通行不可。Ctrl/Cmd+Cで複製、Xで回収、Vで前方空き床に置く。水場の橋にした通常木箱は固定 |
| スキルポーション | `skillPotion` | 接触で取得し、使用できる貼り付け回数を回復 |

| shortcutGate | 1マス | コピー成功まで通行不可。成功後に開く |
| 色スイッチ | `colorSwitches` | 同色の色つき木箱を置くと色壁を開く |
| 色壁 | `colorWalls` | 対応色が有効になるまで通行不可 |
| レーザー | `lasers` | レーザービームに触れると即ゲームオーバー |
| 水場 | `water` | 空の水マスは進入不可。通常木箱を置くと渡れる足場になる |

## 木箱とレーザー

- ノーマル木箱はレーザーを恒久的に遮る。
- 色つき木箱はレーザーを遮らない。
- レーザー発射装置のマスには入れない。

## 1ターンの解決順序

1. 移動先が占有可能か確認する。
2. 移動を確定して向きを更新する。
3. ポーション取得を判定する。
4. 空の水マスへの移動を拒否し、レーザーは進入時だけ判定する。
5. ゴールに到達したら次のステージへ進む。

水マスに置かれた通常木箱は橋として固定され、コピー・切り取り・Undoで取り除けない。ゲームオーバー時は入力停止、R/Enterで現在ステージを再読込する。全ステージクリア後はクリア画面を表示し、R/Enterで最初から再開する。
