# ギミック仕様（既存 `MainGameScene` 準拠）

以下は既存実装の動作。名称や発火条件を変えない。

| 要素 | データ | 挙動 |
|---|---|---|
| 固定壁 | `obstacles` | 常に通行不可。矩形で定義 |
| 木箱 | `blocks` | 通行不可。Ctrl/Cmd+Cで複製、Xで回収、Vで前方空き床に置く |
| スキルポーション | `skillPotion` | 接触で取得し、使用できる貼り付け回数を回復 |
| ライフポーション | `lifePotion` | 接触で取得し、HP減少時に回復 |
| shortcutGate | 1マス | コピー成功まで通行不可。成功後に開く |
| goalBlock | 1マス | この座標に木箱が置かれていないとゴールをクリアできない |
| 色スイッチ | `colorSwitches` | 同色の色つき木箱を置くと色壁を開く |
| 色壁 | `colorWalls` | 対応色が有効になるまで通行不可 |
| レーザー | `lasers` | ビーム上でHP-1。約1.2秒の連続被弾防止あり |
| マグマ | `magma` | ノーマル木箱で覆われていないマスに進入すると即ゲームオーバー |

## 木箱とレーザー

- ノーマル木箱はレーザーを5秒間遮る。その後木箱は壊れる。
- 色つき木箱はレーザーを遮れない。
- レーザー発射装置のマスには入れない。

## 1ターンの解決順序

1. 移動先が占有可能か確認する。
2. 移動を確定して向きを更新する。
3. ポーション取得を判定する。
4. マグマとレーザーの危険判定をする。
5. goalとgoalBlock条件を確認する。

ゲームオーバー時は入力停止、R/Enterで `loadStage()` を呼び直す。全ステージクリア後は `BossQuizScene` を開始する。
