# マス・ギミック仕様

## 共通ルール

- マップは左上を `(0, 0)` とする直交グリッド。
- 1マスには地形1つと、必要ならギミック1つを置く。
- すべてのマスは `id` と `type` を持つ。ギミックを追加する時は、見た目・通行可否・発火タイミング・必要な状態をこの文書とステージ形式に追記する。
- 解決順序は **移動可否 → 移動 → 進入時効果 → ショートカット時効果 → クリア判定**。

## MVPのマス

| type | 表示 | 通行 | 効果・仕様 |
|---|---|---:|---|
| `floor` | 床 | 可 | 効果なし |
| `wall` | 壁 | 不可 | 移動を止める |
| `start` | 開始地点 | 可 | プレイヤー初期位置。各ステージ1つ |
| `goal` | ゴール | 可 | 到達でクリア。各ステージ1つ以上 |
| `copy-source` | コピー元 | 可 | `Ctrl/Cmd+C` で同じ `group` のアイテムを保持 |
| `paste-target` | 貼り付け先 | 可 | 対応するアイテム保持中の `Ctrl/Cmd+V` で有効化 |
| `gate` | 扉 | 条件付き | 対応する `group` の貼り付け先が有効になるまで通れない |
| `switch` | スイッチ | 可 | 進入で同じ `group` の扉を開閉する |
| `hazard` | 危険マス | 可 | 進入でステージ開始地点へ戻す。MVPでは残機なし |

## データ例

```json
{
  "id": "copy-gate-intro",
  "name": "コピーで扉を開こう",
  "width": 8,
  "height": 6,
  "tiles": [
    { "x": 1, "y": 1, "type": "start" },
    { "x": 2, "y": 1, "type": "copy-source", "group": "blue" },
    { "x": 4, "y": 1, "type": "paste-target", "group": "blue" },
    { "x": 5, "y": 1, "type": "gate", "group": "blue" },
    { "x": 6, "y": 1, "type": "goal" }
  ]
}
```

## 表現方針

- 壁・床は色だけに依存せず、輪郭・模様・アイコンで識別できるようにする。
- `group` は色に加えて記号（丸、三角、四角）を使う。色覚特性があっても区別できる。
- アクティブなマスには弱い発光、無効な扉には鍵アイコンを表示する。
- 現在保持しているコピー対象はCanvasの上部HUDに表示する。
