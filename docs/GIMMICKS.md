# ギミック仕様（既存 `MainGameScene` 準拠）

ゲームプレイに残すギミックの動作仕様。

| 要素 | データ | 挙動 |
|---|---|---|
| 固定壁 | `obstacles` | 常に通行不可。矩形で定義 |
| 木箱 | `blocks` | 通常は通行不可。Ctrl/Cmd+Cで複製、Xで回収、Vで前方空き床に置く。水場の橋にした通常木箱は固定 |
| 貼り付けポーション | `pastePotion` | 接触で取得し、貼り付け回数を1回回復 |
| 全選択ポーション | `selectAllPotion` | 接触で取得し、Ctrl/Cmd+Aの使用回数を1回回復 |

| 色スイッチ | `colorSwitches` | 同色の色つき木箱が乗っている間だけ、その色が有効になる |
| 色壁 | `colorWalls` | `mode: "open"` は色が有効な間に開く。`mode: "close"` は色が有効な間に閉じる（省略時はopen） |
| レーザー | `lasers` | レーザービームに触れると即ゲームオーバー |
| 水場 | `water` | 空の水マスは進入不可。通常木箱を置くと渡れる足場になる |

## 色スイッチと色壁

- スイッチ上に同じ色の色つき木箱がある間、その色が有効になる。
- `mode: "open"` の色壁は色が有効な間に開き、`mode: "close"` の色壁は有効な間に閉じる。
- 木箱をスイッチから動かすと色は無効になり、開閉状態が反転する。

## 木箱とレーザー

- ノーマル・色つき木箱のどちらもレーザーを恒久的に遮る。
- ビームは壁・障害物・木箱で遮られるまで伸び、長さは最大21マス。
- レーザー発射装置のマスには入れない。

## 1ターンの解決順序

1. 移動先が占有可能か確認する。
2. 移動を確定して向きを更新する。
3. ポーション取得を判定する。
4. 空の水マスへの移動を拒否し、レーザー接触は即ゲームオーバーにする。
5. ゴールに到達したら次のステージへ進む。

水マスに置かれた通常木箱は橋として固定され、コピー・切り取りの対象外。Undoでは配置前に戻せる。Undoはポーション取得と各スキル残数も含めて一手前へ戻す。レーザー接触時はゲームオーバーになり、Ctrl/Cmd+Zで一手戻るかR/Enterで再挑戦できる。全ステージクリア後はクリア画面を表示し、R/Enterで最初から再開する。
