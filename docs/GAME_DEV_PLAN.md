## 1. 対象と現状

本作はキーボードショートカットを使ってダンジョンを解くCanvas 2Dゲームです。ゲームループ、入力、メインシーン、Canvas UI、5ステージ、ステージ検証、操作確認ページを配置済みです。

今回の作業対象は、5ステージの進行、キーボード操作、木箱・色スイッチ・レーザー・水場等の既存ギミック、最終クリア画面です。通常・色つき木箱はレーザーを恒久的に遮ります。ビームは遮られるまで最大21マス伸びます。接触は即死で、死亡後にUndoで一手戻るか、再挑戦を選べます。水場は通常木箱で橋にし、橋の木箱はコピー・切り取り不可ですがUndoで戻せます。

## 2. 担当境界

- 末田: `src/core/`、`src/scenes/`、`src/ui/canvas-ui.js`、ゲーム確認ページ。
- 白鳥: ステージ仕様、ステージJSON、`packages/stage-schema/`。
- 須賀: `src/main.js`、`index.html`、共通CSS、ルート `package.json`。
- 白石: 認証、セーブ、Supabase接続。ゲームシーンからSupabaseを直接呼びません。
- `.env.local` 以外にSupabaseの実値を置かず、新しいゲームエンジンやUIフレームワークを追加しません。

### P5: Ctrl+A 複数ブロック選択

### 要件

- Ctrl/Cmd+Aで、ステージ上の操作可能なブロックをすべて選択する。水場を橋にした固定木箱は選択対象から除く。
- 選択ブロックはタイル外周の明るい輪郭とチェック印で判別できる。
- 選択状態でCtrl/Cmd+C/Xを使う場合、プレイヤーの向いている前方1マスのカーソルが選択ブロック上にあることを必須とする。コピー・切り取りは選択ブロック全体を対象にする。
- そのブロックを基準に相対位置を保ってクリップボードへ記録する。切り取りは一操作としてUndo/Redoできる。
- Ctrl/Cmd+Vでは、現在向いている前方1マスに基準ブロックを置く。コピー/カット時と向きが違えば、選択全体を回転し相対配置を保って貼る。貼り付け・全選択は各専用エナジーを1回分消費する。
- 予定位置のいずれかが壁と重なる場合は衝突を明示して貼り付けを拒否する。複数の一部だけを貼ることはしない。他の配置不能マスや水場の箱種制約も事前検査する。
- 選択、コピー、切り取り、貼り付け、Undo/Redo後の選択表示・クリップボード・レーザー判定・色スイッチを整合させる。

4. ステージ検証、本体ビルド、プレイページで回帰確認する。

## 4. 受け入れ条件

- 矢印キー/WASDで1マス移動し、壁、木箱、閉じた色壁、レーザー発射器を通過しない。
- Ctrl/Cmd+Aは全選択回数を消費し、操作可能な全ブロックを選択表示する。固定橋は選択されない。
- Ctrl/Cmd+C/Xは選択群のブロックをカーソルで指定した時だけ全体へ作用し、Ctrl/Cmd+Vでコピー時と貼り付け時の向き差分だけ回転して貼り付ける。壁との衝突時は全件を拒否して警告する。
- Ctrl/Cmd+C/X/V/Z/Yでコピー、切り取り、貼り付け、Undo、Redo。Alt付き操作は無効。
- スキルポーション、色スイッチ、色壁、レーザー、水場が動作。
- レーザービームに触れると即ゲームオーバー。
- 空の水マスには入れず、通常木箱を置くと渡れる。橋の木箱は移動・削除できない。
- 5ステージクリア後はクリア画面を表示し、R/Enterで最初から再開。
- `dispose()` でキーボードとCanvasクリックのイベントを解除。
- 複数ブロック貼り付けは壁などの衝突時に部分配置せず、貼り付けエナジーも消費しない。
