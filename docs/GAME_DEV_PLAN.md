# ng_2611 開発計画

更新日: 2026-10-24  
担当: 末田（ゲーム本体・操作体験）

## 1. 対象と現状

本作はキーボードショートカットを使ってダンジョンを解くCanvas 2Dゲームです。ゲームループ、入力、メインシーン、Canvas UI、5ステージ、ステージ検証、操作確認ページを配置済みです。

今回の作業対象は、5ステージの進行、キーボード操作、木箱・色スイッチ・レーザー・水場等の既存ギミック、最終クリア画面です。通常木箱はレーザーを恒久的に遮り、色つき木箱はレーザーを遮りません。レーザーは進入時だけダメージを与えます。水場は通常木箱で橋にし、橋の木箱は固定します。

## 2. 担当境界

- 末田: `src/core/`、`src/scenes/`、`src/ui/canvas-ui.js`、ゲーム確認ページ。
- 白鳥: ステージ仕様、ステージJSON、`packages/stage-schema/`。
- 須賀: `src/main.js`、`index.html`、共通CSS、ルート `package.json`。
- 白石: 認証、セーブ、Supabase接続。ゲームシーンからSupabaseを直接呼びません。
- `.env.local` 以外にSupabaseの実値を置かず、新しいゲームエンジンやUIフレームワークを追加しません。

## 3. 開発手順と進捗

### P0: 既存実装と仕様の照合 — 完了

- リポジトリ内の担当README、仕様、ステージ契約と正規実装を確認。
- 担当境界と既存のルート入口を維持。

### P1: ゲーム本体の配置 — 完了

- ゲームループ、入力、ステージ進行、Canvas UI、メインシーン、5ステージとスキーマ検証を配置。
- `dev/play.html` を操作確認用の入口として用意。
- ルートの `src/main.js`、`index.html`、`package.json` は統合担当の管理範囲として維持。

### P2: ゲーム進行とギミック — 完了

- 5ステージの最後にクリア画面を表示。R/Enterで最初から再開。
- 通常木箱でレーザービームを遮り、色つき木箱はビームを通す。
- HP表示・HP判定・ライフポーションをなくし、レーザービームに触れると即ゲームオーバー。
- 空の水マスは通行不可。通常木箱で橋にすると通行可能になり、その木箱は固定される。

### P3: 統合準備 — 契約確認済み、接続待ち

- `home-integration/README.md` はホームから `startGame()` を呼ぶ構成を示すが、現在の `src/main.js` は準備中の表示のみで、ゲーム開始・クリア通知の実装契約は未定義。
- 統合担当が公開APIを用意した後、ゲーム側のクリア通知を接続する。統合担当の管理ファイルは変更しない。

### P4: 受け入れ確認 — 一部確認済み

- ステージ検証、本体ビルド、プレイページビルド、ゲーム状態遷移のスモーク確認を実施。
- 未確認: ブラウザー上の操作、5ステージ通し、Windows/Macキー操作、イベント解除。
- デモ手順とREADMEの製品説明をチームで確定。

## 4. 受け入れ条件

- 矢印キー/WASDで1マス移動し、壁、木箱、閉じたゲート、閉じた色壁、レーザー発射器を通過しない。
- Ctrl/Cmd+C/X/V/Z/Yでコピー、切り取り、貼り付け、Undo、Redo。Alt付き操作は無効。
- スキルポーション、色スイッチ、色壁、レーザー、水場が動作。
- レーザービームに触れると即ゲームオーバー。
- 空の水マスには入れず、通常木箱を置くと渡れる。橋の木箱は移動・削除できない。
- 5ステージクリア後はクリア画面を表示し、R/Enterで最初から再開。
- `dispose()` でキーボードとCanvasクリックのイベントを解除。
