    操作ガイド / MANUAL

    このダンジョンでは、実際のPCショートカットがそのまま魔法になります。 向いている方向の1マスに対して操作が働きます。

    Ctrl + C
    目の前の木箱をコピーする。コピー元は消えない。
    Ctrl + V
    コピーした木箱を目の前に貼り付ける。エナジーを1消費。
    Ctrl + X
    目の前の木箱を切り取る。貼り付けるまで手元に保持。
    Ctrl + Z
    直前の操作を取り消す。
    R / Enter
    ゲームオーバー時に現在のステージをやり直す。

    進捗はステージクリア時に自動保存されます。Ctrl + S を押す必要はありません。
