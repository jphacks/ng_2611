    あそびかた

    このダンジョンでは、パソコンのショートカットが魔法になるよ。 向いている方向の1マスに対して操作が働きます。

    Ctrl + A
    木箱をぜんぶ選ぶ。全選択ポーションが必要。
    Ctrl + C
    目の前の木箱をコピーする。元の木箱はそのまま。
    Ctrl + V
    コピーした木箱を目の前にはる。回数を1使う。
    Ctrl + X
    目の前の木箱を切り取る。はるまでコピーに残る。
    Ctrl + Z
    一手前にもどす。ゲームオーバーのときも使えるよ。
    R / Enter
    ゲームオーバーのとき、最初からやりなおす。

    ステージをクリアすると、自動で保存されるよ。
